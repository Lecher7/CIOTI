DUpaypal 3.1

OVERVIEW

DUpaypal is a free Paypal-based E-Commerce storefront. Backend by Access database, DUpaypal can store thousands of products in category with images. Each product is displayed with full detail and description, also with its related products. You can customize DUpaypal to sell only the products that you want to offer your customers such as books, games, or CDs or clothes. DUpaypal is an excellent add-on for your Web site. Start selling your products and attracting more customers to your site by using this free application.

SPECIFICATIONS

DUpaypal is an easy-to-use ASP-based storefront which can be completely customized to seamlessly match your site's look and feel:

- Utilizing Microsoft Active Server Pages that can be tested and hosted on any Windows-based PCs and servers
- Unlimited categories with product counter
- Unlimited products with images and full description
- Complete search feature that helps visitors find just the products they're looking for
- Related products are shown for each product's detail view
- Shipping cost included
- Works with US, Canada, British, European and Japanese currency

DUpaypal comes with a Web-based Admin panel, you will be able to perform all of the following:

- Password-protected Admin panel
- Fast, real time image uploading
- Add new category, delete existing categories
- Add new products, edit and delete existing products

Add-ons and updates can be found online

Please check the Professional version of this application for more advance features.

SET UP

After you unzipped DUpaypal.zip, you can either rename DUpaypal folder to something else you prefer such as "shop" or "store" or keep its original name as DUpaypal.

There is a file named inc_config.asp. You need to open this file and replace the default Paypal account ID with your own ID. If you do not have an ID, go to paypal.com and open a free account there.

Finally, use an FTP program such as CuteFTP to upload all files and folders to your site server.

If your site domain is yourdomain.com, and you do not rename the original main folder DUpaypal, and you upload this whole DUpaypal folder to the root of your site, the URL to your DUpaypal front page is:

http://www.yourdomain.com/DUpaypal/

The URL to Admin is:

http://www.yourdomain.com/DUpaypal/admin

The default Admin account is

Admin ID: admin
Password: password

Login and you will be able to change the default password to something else.
